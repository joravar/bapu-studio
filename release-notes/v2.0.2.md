## Bapu Studio v2.0.2

Two more fixes on top of v2.0.0/v2.0.1, closing a couple of the remaining gaps versus Postman.

### Fixes

- **Multi-tab request editor.** You can now have several requests open at once, Postman-style — switching to a different request in the sidebar used to silently discard whatever you were editing in the single request pane; it now opens in its own tab, and each tab keeps its own unsaved edits until you explicitly save or close it.
- **Collection "+" button.** The "+" next to a collection in the sidebar was wired to "save the currently active request into this collection," so it looked like "add a new request" but actually copied in whatever you happened to have open. It now creates an actual new blank request directly inside that collection.

### Also included (from v2.0.1)

- Windows `Setup.exe` installer (alongside the portable `.exe`)
- Fixed macOS and Windows release-build failures in CI
- Direct "Import Bapu Studio JSON" option for collections already in the app's native format

See the [v2.0.0 release notes](https://github.com/joravar/bapu-studio/releases/tag/v2.0.0) for the full pure-Rust rewrite writeup.
