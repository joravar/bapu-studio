## Bapu Studio v2.0.0 — Pure-Rust Native Rewrite

Bapu Studio is now a ground-up **100% native Rust** desktop app (`egui` / `eframe`) — no more Electron, Chromium, Node.js, or bundled JVM. Same local-first, zero-telemetry philosophy, a fraction of the RAM, and a sub-second cold start.

### Highlights

- **100% pure-Rust architecture.** The whole app — UI, HTTP client, database drivers, script sandbox, secrets vault — is one native Rust workspace (`native/crates/bapu-core` + `native/crates/bapu-app`). No browser runtime, no IPC bridge.
- **33 database engines**, each over a native Rust driver or protocol — no bundled JDBC/ODBC runtimes required for most of them. Highlights: PostgreSQL/CockroachDB/YugabyteDB/TimescaleDB (`sqlx`), MySQL/MariaDB/TiDB (`sqlx`), SQLite, pure-Rust **MSSQL/Azure SQL** (`tiberius` TDS), pure-Rust **Oracle 19c–23ai** (`oracle-rs` TNS thin protocol), MongoDB, Redis/Valkey/Dragonfly, Cassandra/ScyllaDB (`cdrs-tokio`), Snowflake, BigQuery, Databricks SQL, ClickHouse, Elasticsearch/OpenSearch, Neo4j, and more — see the full engine table in the [README](https://github.com/joravar/bapu-studio#️-33-supported-database-engines).
- **DBeaver-class Database IDE**: interactive ER diagrams (with Mermaid/SVG export), a visual table designer with live DDL preview, multi-tab SQL editor with formatter and `EXPLAIN` plans, a transactional Data Grid (staged edits with real `BEGIN`/`COMMIT`/`ROLLBACK`) with bidirectional FK navigation, schema/data diffing, FK-aware mock data seeding, and 8-format export (CSV/TSV/JSON/NDJSON/SQL/Markdown/HTML/XML).
- **Postman-class API Studio**: full method/payload matrix including GraphQL, OAuth2/AWS SigV4/JWT auth, scoped variables with a cookie jar, a sandboxed `boa_engine` JS runtime for pre-request/test scripts (zero filesystem/network/OS access by design), a collection runner, a local mock server, 8-language code generation, and OpenAPI/HAR/Postman/cURL import-export.
- **OS-keychain secrets vault**: database passwords, SSH credentials, and secret-flagged variables are stored via your OS's native credential store (Windows Credential Manager/DPAPI, macOS Keychain, Linux Secret Service/KWallet) instead of plaintext.
- **Real-time Streams Studio**: WebSocket and SSE connections with a live message log.

### Known gaps vs. the old Electron app

This is a ground-up rewrite, not a 1:1 port. A few v1.x features are still catching up in v2.0: multi-window popout layouts, some AI Copilot providers, and a handful of DBeaver-parity niceties are still being ported. See open issues for the current list, and please file a bug if something you relied on in v1.x is missing.
