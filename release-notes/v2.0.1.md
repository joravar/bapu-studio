## Bapu Studio v2.0.1

A follow-up patch to the v2.0.0 native-Rust rewrite, fixing two gaps found right after launch and a release-pipeline bug that was silently blocking macOS/Windows builds.

### Fixes

- **Windows installer.** Added a proper `Bapu-Studio-Setup-x64.exe` (built with NSIS) alongside the existing portable `.exe` — Program Files install, Start Menu/Desktop shortcuts, and a real uninstaller registered in Add/Remove Programs.
- **Release notes.** GitHub Releases on this repo only auto-generate from PRs, and this repo pushes straight to `main`, so v2.0.0's notes were just a bare compare-link. This and future tagged releases now carry real, hand-written notes.
- **macOS release build was failing.** `odbc-api` linked `libodbc` at compile time, but the release workflow only installed `unixodbc-dev` on the Linux runner. Fixed by gating `odbc-api` to Windows (which ships ODBC natively) and using `libloading`/`dlopen` at runtime on macOS/Linux instead.
- **Windows release build was failing.** The Setup.exe build step assumed NSIS (`makensis`) ships preinstalled on the `windows-latest` runner, like the Windows SDK and ImageMagick do. It doesn't — now installed via Chocolatey when missing.
- **Collection import gap.** A collection JSON already in Bapu Studio's own native format (not Postman/OpenAPI/HAR) had no way to be imported directly — the existing importers didn't recognize that shape and silently produced an empty collection. Added a dedicated "Import Bapu Studio JSON" option.

See the [v2.0.0 release notes](https://github.com/joravar/bapu-studio/releases/tag/v2.0.0) for the full rewrite writeup.
