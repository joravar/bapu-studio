Next-Generation Developer Cockpit — Upgraded in v1.2.1

Everything you need for full-stack API, real-time stream, and database engineering without the bloat.

📑

DBeaver-Style Multi-Tab Scratchpads

Open, rename, and manage multiple concurrent query buffers per database connection. Double-click inline renaming and auto-saving persistence across app restarts.

⚡

Partial Execution & ⚡ Explain Plan

Highlight any query segment to run selected code (Ctrl+Enter / F5). 1-click EXPLAIN query visualizer for PostgreSQL, MySQL, SQLite, and MongoDB executionStats.

📟

Dual Mode: Grid vs. Execution Console

Switch seamlessly between an interactive data grid with CSV export and a detailed Execution Console displaying latency (ms), rows affected, and query execution plans.

🔒

Custom Root CA & Mutual TLS (mTLS)

Connect securely to enterprise databases with custom Root CA certificates (ca.pem), client certificates (mTLS), and client private keys with configurable CA verification.

🚀

REST, GraphQL & cURL Importer

Multi-method HTTP/GraphQL engine with sub-millisecond latency timer, cURL importer, and one-click code generation in TypeScript, Python, Go, and Rust.

⚡

WebSocket & Server-Sent Events

Live stream listener and bidirectional WebSocket console with real-time frame telemetry, connection lifecycle tracking, and JSON payload inspection.

🧪

Postman & OpenAPI 3.0 Engine

Execute pre-request scripts and automated assertions with pm.test, pm.environment.set, and bapu.expect. 1-click Postman v2.1 and OpenAPI 3.0 import/export.

🔐

Scoped Secrets Matrix & Real SQLite

Scoped environment variables with secret masking and instant {{VARIABLE}} URL interpolation. Drag-and-drop SQLite file inspection powered by a real sql.js engine — real schema, real queries, real writes.

🔑

SSH Tunnel (Bastion Host)

Reach Postgres, MySQL, MongoDB, or Redis instances that only live inside a private network — password or private-key authentication to the jump host, forwarded automatically.

🧵

Full Redis Driver

Run raw Redis commands (GET, HGETALL, SCAN, ...) against a real connection, with a type-aware keyspace browser and the same SSH/TLS options as your SQL databases.

📁

Git-Friendly Collection Storage

Link an API collection to a folder and it's mirrored as one plain JSON file per request — small, reviewable diffs instead of one opaque blob, so teams can code-review API changes like any other PR.
