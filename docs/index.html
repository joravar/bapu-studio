Schema Diff, PK Data Diff & Mock Seeder

Transactional Grid, FK Jumps & 8 Exports

Stage edits/inserts/deletes inside real BEGIN/COMMIT/ROLLBACK transactions, jump bidirectionally across Foreign Keys, import CSV/JSON with column mapping, and export in 8 formats.

REST, GraphQL, Multipart & Enterprise Auth

All 7 HTTP methods, :path params, Multipart file uploads, GraphQL schema introspection, OAuth 2.0 live token exchange, AWS Signature v4, JWT HS256, and RFC-6265 Cookie Jar.

🧪

Air-Gapped JS Sandbox & Auto-Assertions

Run bapu.* / pm.* pre-request and assertion scripts inside a pure-Rust boa_engine sandbox (zero network/FS access, 5s timeout) or generate assertions in 0ms.

🏃

Collection Runner, Mock Server & Codegen

Run data-driven CSV/JSON test suites with avg/p95 latency stats, spin up a local HTTP Mock Server from saved examples, and generate client code in 8 languages.

OpenAPI 3, HAR 1.2, Postman & Git Sync

Lossless import/export for OpenAPI 3.0/3.1, HAR 1.2, Postman v2.1, cURL, and Markdown API docs — plus 1-file-per-request Git directory sync for clean PR diffs.

OS Keychain Vault, mTLS & SSH Bastion

Local Ollama & BYOK AI Copilot
